## 已完成的真实基线实验

### LoMa

- 官方LoMa-B128、官方路径预处理、2048个关键点、CPU四线程
- HardMatch validation固定3对真实建筑图像：样本mAA@10px为 **0.598252**
- 匹配耗时 **9.91–10.49秒/对**，进程峰值RSS约 **1550MiB**
- 评价范围为3对validation图像，900对正式test与新增方法评价待进行
- [实验记录与复跑材料](baselines/20261018-loma-official-preprocess/README.md)

### TAPNext++

- 官方256²权重与逐帧接口；DAVIS `bike-packing`，第0个查询点，帧0–15
- CPU四线程，16帧前向 **42.04秒**，后续帧均值 **2.635秒/帧**，峰值RSS约 **3676MiB**
- 官方first-query评分排除查询帧，实际评价15个位置；该点在片段中全程可见，AJ、δ平均值和OA均为1.0
- 当前片段验证了输入输出和计算成本；遮挡、重检测及突发丢帧实验待进行
- [实验记录与复跑材料](baselines/20261018-tapnextpp-davis16/README.md)

### AnyCalib

- 官方anycalib_gen与原预处理，LaMAR首条CSV记录95419735117.jpg，已知pinhole相机族
- CPU推理 **2.592秒**、加载 **3.640秒**，进程峰值RSS约 **2759MiB**
- 官方评分：最大相对焦距误差 **2.454%**、平均射线角误差 **0.454°**、垂直视场角误差 **1.203°**
- 本次完成已知模型单图标定；未知相机族选择及裁切一致性实验待进行

## 资源和实施顺序

当前运行环境为CPU、约10GB内存，无GPU。LoMa、TAPNext++与AnyCalib已验证CPU小样本可行；SubspaceAD可从DINOv2-S/224的小规模配置开始。D2Dewarp需适配设备映射，ZeroPlane包含较重权重和编译依赖，适合GPU条件就绪后推进。各题的参数量、输入尺度与资源估计见总表。

每个候选按以下阶段推进：

1. 固定官方版本、权重、真实样本、命令和评价协议，完成基线
2. 检查提出的失败机制是否在独立样本上出现
3. 实现最小改进，与直接近邻及简单方法同预算比较
4. 做消融、外部验证和失败案例分析，形成项目报告

## 备选与归档方向

- **SubspaceAD PCB微缺陷**：机制诊断备选；先验证Patch采样相位效应，再决定是否推进改进
