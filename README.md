## 目录约定

- `course-requirements/`：开题要求证据与内容检查表
- `research/`：候选、论文、官方实现、数据集直链与近邻方法比较
- `experiments/`：版本、命令、环境、原始结果、测试日志与demo清单
- `slides/`：各选题的开题汇报PPT及预览
- `docs/`：详细选题文档与实验协议
- `manifests/`：产物版本与SHA256校验
